Plugins

Packs de skills, commandes et MCP livrés ensemble. Installable en 1 commande.

C'est quoi, un plugin ?

Un plugin Claude Code, c'est un bundle qui peut contenir : plusieurs skills, des commandes custom, des hooks, voire des MCP préconfigurés. Au lieu de tout installer à la main, vous lancez /plugins install <nom> et tout arrive en bloc.

Métaphore. Une skill = une fiche métier. Un plugin = la mallette complète d'un corps de métier (toutes les fiches + les outils).

Comment installer ?

Parcourir le marketplace
/plugins
Installer un plugin par nom
/plugins install <nom-du-plugin>
Lister les plugins installés
/plugins list
Désinstaller
/plugins uninstall <nom-du-plugin>

Plugins productivité

verify

Vérifie qu'un changement fait vraiment ce qu'il prétend, en lançant l'app et observant le comportement.

simplify

Review le code récemment modifié et propose simplifications, refactos, dead code à supprimer.

schedule

Programme des routines cron pour Claude (exécution remote sur cloud Anthropic).

loop

Répète un prompt à intervalle régulier (poll d'un déploiement, vérification de stat).

Créer son propre plugin

Vous pouvez créer un plugin pour packager vos propres skills + commandes et le publier sur GitHub pour vos collègues.

Structure d'un plugin
mon-plugin/ ├── plugin.json # metadata du plugin ├── skills/ │ ├── ma-skill-1/SKILL.md │ └── ma-skill-2/SKILL.md ├── commands/ │ └── ma-commande.md └── README.md

Pour publier, push sur GitHub puis on installe via :

Installer un plugin depuis GitHub
/plugins install github:cggroupe/mon-plugin
