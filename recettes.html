🎨 Recette 1 — Landing page Stitch en 10 min

Objectif. Partir d'une idée vague (« une landing pour vendre nos formations »), arriver à une maquette HTML/CSS déployée sur Vercel, en 10 minutes.

Pré-requis

  • Claude Code installé
  • MCP Stitch configuré (voir page MCP)
  • Compte Vercel (gratuit, vercel.com)

Étape 1 : générer la maquette

Prompt Stitch — landing AUTAF
Via le MCP Stitch, génère-moi une landing page sombre haut de gamme pour AUTAF (cabinet de courtage en assurances pour artisans BTP). Structure attendue : 1. Hero : titre choc + sous-titre + CTA "Demander mon devis gratuit" 2. Section "Pourquoi AUTAF" : 3 colonnes (économies moyennes, expertise BTP, accompagnement humain) 3. Section "Comment ça marche" : 4 étapes numérotées 4. Section "Témoignages" : 3 cards avec photo + nom + métier + verbatim 5. Section "FAQ" : 5 questions/réponses 6. CTA final + footer (logo, mentions légales, contact) Style : dark mode, accents orange chaud (type #f97316), typo Inter, généreux en espaces, mobile-first. Output : un dossier "landing-autaf/" avec index.html + style.css + assets/, prêt à déployer.

Étape 2 : itérer (1-2 rounds)

Ajustements design
La maquette est bien mais : - Le hero manque de preuve sociale, ajoute "850+ artisans accompagnés" en chiffre clé sous le CTA - Les témoignages : utilise les photos placeholder de unsplash (search "construction worker portrait") - La FAQ : 5 questions est trop, garde les 3 plus critiques pour un visiteur première fois

Étape 3 : déployer sur Vercel

Déploiement
Le dossier landing-autaf est prêt. Déploie-le sur Vercel : 1. Initialise un repo git local 2. Crée un repo GitHub privé "landing-autaf-test" 3. Push 4. Lance "vercel" en CLI pour le déployer 5. Donne-moi l'URL finale et le lien d'admin Vercel Important : ne mets pas de variables d'environnement sensibles, c'est une démo.

✅ Résultat attendu. Une URL Vercel type landing-autaf-test.vercel.app avec la landing déployée. Temps total : 8-12 min.

🎬 Recette 2 — Vidéo TikTok 9:16 en 20 min

Objectif. Partir d'un angle ("Les 3 erreurs des artisans sur leur assurance décennale"), arriver à une vidéo 9:16 prête à publier sur TikTok.

Pré-requis

  • MCP fal.ai configuré (clé + crédit ≥ $30)
  • Skill hyperframes + btp-video-script-v3 installées
  • VS Code dans un dossier dédié video-decennale/

Étape 1 : script verrouillé

Prompt script BTP
Active btp-video-script-v3. Génère un script vidéo 9:16 de 40 secondes pour TikTok @autaf sur le thème "Les 3 erreurs des artisans BTP sur leur assurance décennale". Format DTU 40 : - Hook 5s (bait Cunningham law) : affirmation faussement provocante - 3 erreurs avec exemple chiffré chacune (8-10s par erreur) - CTA 5s : "DM-moi 'DEVIS' pour un audit gratuit" Verrous obligatoires : - Verbatim-lock (texte exact, pas d'improvisation) - Filler-words-ban (no "euh", "tu sais", "quoi") - Metropolitan French from Paris (NOT Quebec) - Chiffres en toutes lettres dans les dialogues Output : 5 clips de 8s (Veo3 standard image-to-video).

Étape 2 : génération clips Veo3

Prompt fal.ai Veo3
Pour chacun des 5 clips du script, génère via le MCP fal : - Modèle : veo3/standard/image-to-video - Image start : trouve une image stock cohérente (Unsplash "construction worker france") - Durée : 8 secondes - Audio : dialogue exact du script + ambiance chantier discrète - Camera : varied (close-up sur clip 1, plan moyen clip 2-4, plan large clip 5) - Style : realistic documentary, natural lighting Budget max : $35 (5 × $7 max). Sauvegarde tous les .mp4 dans output/clips/.

Étape 3 : assembler avec Hyperframes

Prompt Hyperframes assembly
Active la skill hyperframes. Assemble les 5 clips de output/clips/ en une vidéo finale : - Format 1080×1920, 30fps - Captions auto-générées (Whisper) avec style jaune sur fond noir 70% opacity, 1 mot à la fois - Transitions hard cut entre clips - Premier clip : ajoute overlay hook texte "⚠️ ERREUR #1 QUI TUE TON CABINET" pendant 3s - Audio : - Voix off des clips (audio chain : highpass=80 + afftdn + loudnorm -14 LUFS) - Pas de musique de fond pour ce format - Output : output/decennale-final.mp4 Lance le render quand tu es prêt.

Étape 4 : preview + ajustements

Review
Ouvre la vidéo et fais-toi-en une opinion. Si : - Une transition jure → ajuste la durée - Une caption arrive en retard → recale (offset -200ms si nécessaire) - L'audio d'un clip est étouffé → re-render ce clip avec compression différente Donne-moi un récap des ajustements proposés avant d'appliquer.

Étape 5 : publication PostFast

Schedule TikTok
Schedule output/decennale-final.mp4 sur PostFast pour TikTok @autaf : - Date : demain 20h Paris - Caption : "Les 3 erreurs qui ruinent la décennale des artisans 🔨 (épisode 1)" - Hashtags : #BTP #artisan #assurance #decennale #chantier #travaux #france #pourtoi #savoirfaire #conseilpro - Settings : public, comments/duet allowed - Track le postID dans output/scheduled-postids.json

✅ Résultat attendu. 1 vidéo de 30-45s, 1080×1920, schedulée pour publication, budget total ~$35. Temps total : 20-30 min.

🎯 Recette 3 — Prospection 50 leads BTP en 1h

Objectif. Partir d'une cible métier+géo ("plombiers à Brest"), arriver à 50 leads enrichis avec téléphone, email, site et 1 cold email personnalisé par lead.

Pré-requis

  • MCP Apify configuré (token + crédit Apify ≥ 5$)
  • Skill cold-email + customer-research installées
  • VS Code dans un dossier prospection-brest/
  • Optionnel : MCP Pappers ou clé Pappers pour SCI enrichment

Étape 1 : scrape Google Maps

Scrape Apify
Via le MCP Apify, lance l'actor "Google Maps Scraper" (apify/google-maps-scraper) avec : - Search terms : "plombier Brest" - Max places : 50 - Country : France - Language : fr Sauvegarde le résultat brut dans output/maps-raw.json et fais-moi un récap : combien de résultats, % avec téléphone, % avec site web, % avec email.

Étape 2 : enrich (SIRET, dirigeant)

Enrichissement Pappers / Sirene
Pour chaque lead dans output/maps-raw.json : 1. Cherche le SIRET sur l'API Sirene gratuite (api.insee.fr) à partir du nom + ville 2. Si SIRET trouvé, enrichis avec : forme juridique, dirigeant principal, date création, CA estimé 3. Si SCI ou société multi-dirigeants : note tous les associés 4. Filtre out les leads > 50 salariés (hors cible artisan) Output : output/leads-enriched.csv avec colonnes : nom_entreprise, dirigeant, siret, telephone, email, site_web, ville, date_creation, ca_estime, statut_filtre

Étape 3 : recherche d'angle personnalisé

Personalization research
Pour les 20 premiers leads de output/leads-enriched.csv : 1. Si le lead a un site web : fetch la page d'accueil et trouve UN détail spécifique (chantier récent, certification, équipe, anniversaire) 2. Si pas de site : utilise les avis Google Maps pour trouver UN détail (top compliment client, anecdote) 3. Sauve dans output/leads-personnalisation.json sous forme : { "siret": "...", "angle_perso": "phrase courte 1 ligne qu'on peut intégrer dans un email" } Skip les leads où aucun angle clair ne sort.

Étape 4 : génération cold emails

Génération cold emails (skill cold-email)
Active la skill cold-email. Pour chaque lead dans output/leads-personnalisation.json, génère 1 cold email : Objet : court, intriguant, sans buzzwords (max 60 caractères) Corps : - Ligne 1 : pivot personnalisé (angle_perso du lead) - Ligne 2-3 : value prop AUTAF (économie moyenne -22% sur décennale BTP) - Ligne 4 : preuve sociale chiffrée (850+ artisans accompagnés, dont 40+ à Brest) - CTA : low-friction (15 min visio, pas d'engagement) - Sign-off : Philippe, fondateur AUTAF Ton : sénior, B2B, pas hype, pas d'emoji, pas de "j'espère que vous allez bien". Output : output/emails-cold.json (siret, email, objet, corps).

Étape 5 : envoi via Gmail ou outil de cold mailing

Envoi (test sur 5 d'abord)
Via le MCP Gmail, envoie un test sur les 5 premiers emails de output/emails-cold.json. Cible MA boîte philippe@autaf.fr en bcc pour validation. Si l'A/B test est OK (taux ouverture > 35% après 24h), lance le reste via Lemlist / Instantly / Mailshake (export CSV depuis output/emails-cold.json).

✅ Résultat attendu. 50 leads scrapés + enrichis, 20 leads avec angle perso, 20 cold emails personnalisés prêts à envoyer. Coût Apify ~3$, coût Claude ~5$. Temps total : 45-90 min selon les itérations.
