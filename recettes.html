Scrape
Via MCP Apify, lance apify/google-maps-scraper : - Search : "plombier Brest" - Max places : 50 - Country : France - Language : fr Sauvegarde brut dans output/maps-raw.json. Récap : combien de résultats, % avec téléphone/site/email.
Enrich Sirene
Pour chaque lead dans output/maps-raw.json : 1. Cherche SIRET sur api.insee.fr à partir du nom + ville 2. Enrichis : forme juridique, dirigeant, date création, CA estimé 3. Si SCI : tous les associés 4. Filtre out > 50 salariés Output : output/leads-enriched.csv
Angle perso
Pour les 20 premiers leads : - Fetch leur site web → trouve UN détail spécifique (chantier récent, certification, anniversaire) - Sinon avis Google Maps → UN compliment top Sauve output/leads-personnalisation.json {siret, angle_perso}. Skip les leads sans angle clair.
Cold email
Active cold-email. Pour chaque lead avec angle perso : - Objet : court, intriguant (max 60 caractères) - Corps : pivot angle perso + value prop AUTAF (-22% décennale) + preuve sociale (850+ artisans dont 40 à Brest) + CTA low-friction (15 min visio) - Sign-off : Philippe, fondateur AUTAF - Ton : sénior B2B, pas hype, pas d'emoji, pas de "j'espère que vous allez bien" Output : output/emails-cold.json
Test 5 → bulk
Via MCP Gmail, envoie les 5 premiers emails. BCC philippe@autaf.fr pour validation. Si test OK 24h (taux ouverture > 35%) → exporte CSV pour Lemlist / Instantly et lance le reste.
