Publication

PostFast, Make.com, n8n. Comment publier et programmer vos contenus depuis Claude Code.

Les 3 outils du pipeline

RECOMMANDÉ

📱 PostFast

Publication multi-plateformes (TikTok, Instagram, LinkedIn, X). Simple, API directe, schedule fiable.

ALTERNATIVE

⚙️ Make.com

Plateforme de workflow no-code. Connecte 1500+ apps. Plus puissant mais plus de setup.

POWER USER

🔧 n8n

Alternative open-source à Make. Self-hostable. Workflows complexes, transformation de données.

PostFast — le pipeline @btpmindset

Où chopper la clé API

  1. Allez sur postfa.st
  2. Créez un compte (free trial 7 jours)
  3. Connectez vos comptes TikTok / Instagram / LinkedIn dans Settings → Social Accounts
  4. Allez dans Settings → API
  5. Générez votre API token

Schedule une vidéo TikTok depuis Claude

Prompt complet
Programme cette vidéo sur PostFast pour publication TikTok ce soir à 20h Paris : - Fichier : output/clip-final.mp4 - Caption : "Les 5 erreurs des artisans BTP qui leur coûtent 10k€ par an 🔨" - Hashtags : #BTP #artisan #chantier #savoirfaire #travaux #france #pourtoi - Public : oui - Comments / Duet / Stitch : allowed - Save le post ID dans output/scheduled-postids.json (tracking local obligatoire)

🚨 Bug connu PostFast. L'API /social-posts?limit=50 renvoie 2 à 50 items au hasard, hasNextPage=false menteur. Toujours tracker localement les post IDs dans un fichier JSON, sinon vous risquez les doublons.

Make.com — workflow Apify → Claude → PostFast

Exemple : tous les lundis, scrape les tendances TikTok, demande à Claude un script vidéo, génère via fal.ai, publie via PostFast.

Où chopper la clé API

  1. Allez sur make.com et créez un compte (plan gratuit OK pour démarrer)
  2. Dans Profile → API, copiez votre Make API token

Trigger un scenario Make depuis Claude

Webhook trigger
Lance le scenario Make "veille-tiktok-hebdo" via son webhook URL https://hook.eu1.make.com/xxxxx avec ce payload : { "trigger": "weekly", "topic": "tendances BTP TikTok semaine 22", "output_destination": "postfast" }

n8n — self-hosted workflow

n8n est l'alternative open-source à Make. On l'utilise quand on veut héberger soi-même (VPS) et avoir des workflows complexes.

⚠️ Piège connu. Dans n8n v2.8+, la variable $env est bloquée. Vous devez hardcoder les valeurs ou passer par des credentials n8n natifs. JAMAIS utiliser le nœud "Schedule" pour les process longs : utiliser systemd à la place.

Trigger un workflow n8n depuis Claude

Webhook trigger n8n
Trigger le workflow n8n "prospection-bretagne" via webhook https://n8n.mondomaine.com/webhook/prospection-bretagne avec ce payload : { "department": "29", "metier": "couvreur", "limit": 100, "enrichment": ["pappers", "dehashed"] } Le workflow va scraper, enrichir, écrire des emails personnalisés et me retourner un CSV.

Pipeline complet : génération → publication

Voici la recette complète que Claude peut orchestrer end-to-end :

1. Claude lit le calendrier édito (skill btp-content-calendar)
2. Claude génère 7 scripts vidéo (skill btp-video-script-v3)
3. Pour chaque script :
   - Génère voix off (ElevenLabs ou Kokoro)
   - Génère clips Veo3 (fal.ai MCP)
   - Assemble avec Hyperframes
   - Génère captions (Whisper)
4. Claude upload tous les .mp4 sur PostFast
5. Claude programme les 7 posts en alternance 20h/12h
6. Claude écrit le tracking dans wiki/log.md (pattern Karpathy)
7. Claude envoie un Slack récap : "7 vidéos schedulées, coût total $168"

Le prompt master

Prompt pipeline complet
Mission : produire et programmer 7 vidéos TikTok pour la semaine prochaine sur le thème "Erreurs BTP qui coûtent cher". Pipeline : 1. Active btp-content-calendar et propose 7 angles 2. Pour chaque angle : - Génère script avec btp-video-script-v3 (verbatim-lock + filler-words-ban) - Génère voix off ElevenLabs Nicolas v3 émotionnel - Génère 5 clips Veo3 via fal.ai (mode standard, 8s chacun) - Assemble avec Hyperframes (1080×1920, captions jaunes) - Audio chain : highpass 80 + denoise + loudnorm -14 LUFS 3. Upload tous les fichiers sur PostFast 4. Schedule 7 posts du lundi au dimanche, alternance 20h/12h Paris 5. Hashtags signature : #BTP #chantier #artisan #savoirfaire #travaux #france + métier 6. Track post IDs dans wiki/log.md (pattern Karpathy) 7. Budget max : $200 total. Si tu dépasses, stop et demande validation. Démarre en mode plan, je valide avant exécution.
