Installer & démarrer

De zéro à votre premier prompt Claude Code en 30 minutes, étape par étape.

🎯 Objectif de cette page. À la fin, vous aurez : VS Code installé, un compte Anthropic actif, Claude Code opérationnel sur votre machine, et vous aurez fait tourner votre premier prompt.

Pré-requis matériel

  • Un Mac (macOS 12+) ou un PC Windows 10/11
  • Une connexion internet stable
  • Une carte bancaire (pour l'abonnement Anthropic à 20$/mois minimum)
  • 30 minutes devant vous, sans dérangement

Le parcours en 6 étapes

  1. Télécharger Visual Studio Code (5 min)

    VS Code, c'est l'éditeur de texte intelligent dans lequel on va faire vivre Claude Code. C'est gratuit, c'est Microsoft, c'est solide.

    • Allez sur code.visualstudio.com
    • Cliquez sur le gros bouton bleu qui détecte votre OS (Mac ou Windows)
    • Installez normalement (double-clic sur le fichier téléchargé, suivez les instructions)
    • Lancez VS Code une fois pour vérifier qu'il s'ouvre

    Mac avec processeur M1/M2/M3 ? Prenez la version "Apple Silicon", elle est plus rapide.

  2. Créer un compte Anthropic (5 min)

    Anthropic, c'est la boîte qui fait Claude. Le compte sert à payer Claude Code et à gérer vos clés.

    • Allez sur claude.ai
    • Cliquez "Sign up" en haut à droite
    • Utilisez votre adresse email pro
    • Vérifiez votre boîte mail et cliquez le lien de validation

  3. Choisir votre formule (5 min)

    Il y a deux mondes : l'abonnement tout-compris ou la clé API à la consommation. Pour démarrer en marketing, c'est l'abonnement.

    RECOMMANDÉ

    Claude Pro — 20$/mois

    Pour tester sérieusement. Limite raisonnable d'usage quotidien. Inclut Claude Code via la web app et le terminal.

    POWER USER

    Claude Max — 100$ à 200$/mois

    5x à 20x la quota Pro. Pour ceux qui vont vraiment l'utiliser tous les jours (vidéo, prospection lourde).

    Pour souscrire : connectez-vous à claude.ai, cliquez votre avatar en bas à gauche → Settings → Plans → choisissez Pro ou Max.

    ⚠️ Ne pas confondre. Il existe aussi console.anthropic.com qui sert pour les clés API (paiement à l'usage). Ce n'est pas ce qu'on utilise ici. On reste sur claude.ai.

  4. Installer Claude Code (5 min)

    Claude Code, c'est l'agent qui tourne dans votre VS Code. Deux options pour l'installer.

    Option A — Extension VS Code (la plus simple)

    • Ouvrez VS Code
    • Dans la barre latérale gauche, cliquez sur l'icône "Extensions" (⊞)
    • Tapez Claude Code dans la recherche
    • Cliquez "Install" sur l'extension officielle Anthropic
    • Une nouvelle icône apparaît dans la barre latérale : c'est Claude Code

    Option B — Ligne de commande (CLI)

    Si vous voulez utiliser Claude Code dans le terminal (utile pour les power users), ouvrez un terminal et lancez :

    Installation CLI (Mac/Linux)
    curl -fsSL https://claude.ai/install.sh | bash

    Sur Windows, utilisez PowerShell avec :

    Installation CLI (Windows PowerShell)
    irm https://claude.ai/install.ps1 | iex

  5. Se connecter à votre compte (3 min)

    Première ouverture de Claude Code, il va demander de se connecter.

    • Cliquez l'icône Claude Code dans VS Code (panneau latéral)
    • Cliquez "Sign in"
    • Votre navigateur s'ouvre sur claude.ai → autorisez la connexion
    • Revenez sur VS Code : vous êtes connecté

    ✅ Vérification. Vous devez voir un champ de chat dans VS Code avec "How can I help today?" Si oui, vous êtes prêt.

  6. Premier prompt (5 min)

    On va faire le premier "Hello World" pour vérifier que tout tourne.

    • Dans VS Code, allez dans File → Open Folder
    • Créez un nouveau dossier sur votre bureau : mes-tests-claude
    • Ouvrez-le dans VS Code
    • Ouvrez Claude Code (panneau latéral)
    • Tapez ce premier prompt :
    Premier prompt
    Bonjour Claude. On va faire connaissance. Crée-moi un fichier appelé "bonjour.md" qui dit "Hello, je suis prêt." en français. Rien de plus.

    Claude Code va :

    1. Comprendre la demande
    2. Vous demander l'autorisation de créer le fichier (cliquez "Allow")
    3. Créer bonjour.md dans votre dossier
    4. Vous dire ce qu'il a fait

    🎉 Bravo. Vous venez d'utiliser Claude Code pour la première fois. Tout le reste de cette formation, c'est juste des recettes plus poussées de ce même principe.

Et maintenant ?

Vous êtes opérationnel. Voici la suite recommandée :

SUIVANT

Les 8 commandes vitales

/help, /clear, /init, /memory, /agents, /skill, /plan, /plugins. La base à connaître par cœur.

 ENSUITE

Brancher les outils externes

Stitch (design), fal.ai (vidéo), Apify (scraping). Avec les liens pour chopper chaque clé API.

Quelques pièges à éviter dès le début

1. Ne lancez pas Claude Code dans votre dossier home. Toujours créer un dossier dédié par projet. Sinon Claude va se perdre dans toute votre arborescence Mac/PC.

2. Lisez avant de cliquer "Allow All". Quand Claude veut faire une action (créer un fichier, lancer une commande), il demande l'autorisation. Lisez ce qu'il propose. Surtout les commandes qui commencent par rm, delete, git push --force.

3. Si vous bloquez, n'insistez pas en boucle. Claude Code peut "boucler" sur une mauvaise piste. Tapez /clear pour redémarrer le contexte et reformulez votre demande.

Si vous avez un souci durant l'installation, allez voir la page SOS pannes.
