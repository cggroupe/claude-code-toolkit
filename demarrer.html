Les 6 étapes

  1. Télécharger VS Code (5 min)

    VS Code = l'éditeur intelligent dans lequel Claude Code va vivre. Gratuit, Microsoft, solide.

    code.visualstudio.com
    → Aller sur code.visualstudio.com
    → Cliquer le gros bouton bleu (il détecte votre OS)
    → Installer normalement (double-clic + suivre)
    → Lancer VS Code pour vérifier

    Mac M1/M2/M3 ? Prenez "Apple Silicon", plus rapide.

  2. Créer un compte Anthropic (5 min)

    Anthropic = la boîte qui fait Claude. Le compte sert à payer + gérer les clés.

    Étapes
    1. Aller sur claude.ai 2. Cliquer "Sign up" en haut à droite 3. Utiliser votre adresse email pro 4. Vérifier la boîte mail + cliquer le lien

  3. Choisir votre formule (5 min)

    Pour démarrer en marketing = abonnement "tout-compris" (pas la clé API à l'usage).

    RECOMMANDÉ

    Claude Pro — 20$/mois

    Pour tester sérieusement. Quotas raisonnables. Inclut Claude Code via web et terminal.

    POWER USER

    Claude Max — 100-200$/mois

    5x à 20x quota Pro. Pour usage quotidien intense (vidéo, prospection).

    ⚠️ Ne pas confondre. console.anthropic.com = clés API à l'usage (avancé). On reste sur claude.ai ici.

  4. Installer Claude Code (5 min)

    2 options selon votre niveau de confort.

    SIMPLE

    A · Extension VS Code

    1. Dans VS Code, sidebar gauche : icône Extensions (⊞)
    2. Chercher "Claude Code"
    3. Installer l'officielle Anthropic
    4. Nouvelle icône Claude dans la sidebar
    CLI

    B · Terminal

    Mac/Linux :

    Install Mac/Linux
    curl -fsSL https://claude.ai/install.sh | bash

    Windows (PowerShell) :

    Install Windows
    irm https://claude.ai/install.ps1 | iex

  5. Se connecter (3 min)

    Première ouverture de Claude Code = il demande de se connecter à votre compte.

    1. Cliquer l'icône Claude Code dans VS Code
    2. Cliquer "Sign in"
    3. Navigateur s'ouvre sur claude.ai → autoriser
    4. Retour VS Code : vous êtes connecté

    ✅ Vérification. Vous devez voir un champ de chat "How can I help today?" dans VS Code.

  6. Premier prompt (5 min) — le moment magique

    On va faire le "Hello World" pour vérifier que tout tourne.

    1. VS Code → File → Open Folder
    2. Créer un dossier mes-tests-claude sur le Bureau
    3. L'ouvrir dans VS Code
    4. Ouvrir Claude Code (panneau latéral)
    5. Coller ce prompt :
    Premier prompt
    Bonjour Claude. On va faire connaissance. Crée-moi un fichier appelé "bonjour.md" qui dit "Hello, je suis prêt." en français. Rien de plus.

    Claude va : comprendre, demander l'autorisation, créer le fichier, vous confirmer.

    🎉 Bravo. Vous venez d'utiliser Claude Code. Tout le reste = des recettes plus poussées de ce même principe.
3 pièges à éviter dès le début
PIÈGE 1

Pas Claude Code dans home

Toujours un dossier dédié par projet. Sinon Claude se perd dans toute votre arborescence.

PIÈGE 2

Lire avant "Allow All"

Surtout les rm, delete, git push --force. Une bonne lecture = 0 catastrophe.

PIÈGE 3

Si bloqué : /clear

Claude peut "boucler" sur une mauvaise piste. Tapez /clear et reformulez.
