cg-design stack 🎨

Générateur d'ads multi-marques HTML/CSS + Puppeteer. 122+ templates prêts, charte verrouillée, 0€/mois.

🎯 La stack maison. Cette stack est l'arme secrète interne pour produire des visuels Instagram, LinkedIn et TikTok à la chaîne pour AUTAF, BRH, QualiControl, ProElec et le personal brand Philippe. Vous l'installez en 1 commande sur votre Claude Code.

À quoi ça sert ?

Vous prompts Claude (« fais-moi un visuel IG pour AUTAF qui cible les plombiers ») et la stack produit un PNG 1080×1350 prêt à publier, en respectant la charte de la marque (couleurs, polices, anti-invention factuelle). Pas de Canva, pas de Figma. Du HTML/CSS rendu en image avec Puppeteer.

🎨

AUTAF, BRH, QualiControl, ProElec, WorkRepublic, CG GROUPE corp, personal brand Philippe.

Installation (1 commande)

Sur votre VPS / machine de dev, en root :

Install cg-design stack
mkdir -p /opt/stack && cd /opt/stack \ && curl -L http://72.62.178.237:8940/export/cg-design-latest.tar.gz -o cg-design.tar.gz \ && tar xzf cg-design.tar.gz && rm cg-design.tar.gz \ && cd cg-design && bash install.sh

Le script install.sh va :

  1. Vérifier Node.js 20+
  2. Installer Puppeteer 24 + libs Chromium
  3. Installer Inter + Inter Display dans /usr/share/fonts/opentype/inter/
  4. Setup le service systemd cg-design-api sur port 8940
  5. Ouvrir le port 8940 dans UFW
  6. Faire un premier render de validation
  7. Health check de l'API

Pré-requis machine. Linux (Ubuntu 22.04+ ou 24.04 testé), Node 20+, accès root pour installer fonts et systemd. Sur Mac/Windows pour dev local, lancer sans --systemd : bash install.sh --no-systemd.

Comment l'utiliser depuis Claude Code

Une fois la stack installée, ouvrez Claude Code dans /opt/stack/cg-design/ et lancez un de ces prompts.

Cas A — Nouveau visuel Instagram

Prompt visuel IG ads
Lis ONBOARDING-CLAUDE.md et CLAUDE.md d'abord. Mission : crée un visuel IG Ads 1080×1350 pour AUTAF qui cible les électriciens. Workflow : 1. Identifie la marque : AUTAF (brands/autaf/brand.json) 2. Choisis le pattern : stamp-punchy (artisans direct scroll-stop) 3. Format : ig-portrait-1080-1350 4. Copie un template existant similaire (ex: templates/ig-portrait-1080-1350/autaf-04-electricien.html ou autaf-21-receipt.html) 5. Adapte le copy à l'électricien : pain point spécifique, stat verifiée, CTA AUTAF 6. Render : node src/render.js --template autaf-XX-electricien 7. Lis le PNG output pour vérifier (pas d'overflow, pas de débordement) 8. Update wiki/notes/brand-autaf.md 9. Ajoute une ligne à log.md Respecte la charte AUTAF (navy #241B5D + jaune Stabilo #FFE72B + blanc, General Sans + Waiting for the Sunrise pour annotations). Pas de gradient, pas d'emoji, pas de Google Fonts URL.

Cas B — Carrousel DTU (4 slides techniques)

Prompt carrousel DTU
Lis ONBOARDING-CLAUDE.md (section 3 et 4). Mission : carrousel DTU 25.41 (pose plaques de plâtre BA13) en 4 slides pour Instagram AUTAF. Mode anti-invention : 1. WebSearch + WebFetch sur 2 sources pro (Batirama, CAPEB, Knauf, Industries du Plâtre) 2. Construis un brief tabulaire des valeurs sourcées (avec provenance) 3. Demande validation du brief AVANT de coder 4. Code en n'utilisant QUE les valeurs du brief 5. Style alternance : prendre le style YELLOW (fond jaune) cette fois (le précédent batch était NAVY) Structure : - Slide 1 : tampon DTU 25.41 énorme + cartouche + step 01/04 + H1 punchline + schéma central + bulle "3 règles clés" - Slide 2 : 2-3 panels avec mini-schémas + valeurs cotées - Slide 3 : tableau technique Paramètre / Valeur DTU - Slide 4 : 3 règles (data-num + picto) + CTA "Trouve un plaquiste AUTAF" Render + Read les 4 PNG avant validation.

Cas C — Variantes data-driven (1 template × 12 métiers)

Prompt batch variantes
Mission : à partir du template autaf-21-receipt.html, génère 12 variantes — une par métier (plombier, électricien, maçon, carreleur, peintre, menuisier, charpentier, couvreur, plaquiste, terrassier, conducteur de travaux, agent immo). Pour chaque métier : 1. Crée variants/autaf-21-receipt/.json avec : pain spécifique, prix moyen chantier, stat AUTAF (artisans actifs du métier), CTA personnalisé 2. Render via node src/variants.js --template autaf-21-receipt 3. Output 12 PNG distincts Update log.md et wiki/notes/brand-autaf.md à la fin.

Les 3 patterns esthétiques

PATTERN 1

🎯 stamp-punchy

Direct scroll-stopper. Gros tampons, contrastes forts, message percutant. Pour artisans et particuliers.

PATTERN 2

📰 editorial-premium

B2B sobre éditorial. Typographie soignée, espaces généreux. Pour PME, pros, seniors.

PATTERN 3

📊 data-driven

Institutionnel chiffré. Stats, graphiques, comparatifs. Pour partenaires, notaires, agences.

Les interdits absolus

  • ❌ Pas de gradient flou / halo (Philippe associe ça à du contenu IA)
  • ❌ Pas d'emoji dans les designs
  • ❌ Pas de couleur hors charte (notamment pas de cyan / bleu clair / vert hors marque BRH)
  • ❌ Pas de Google Fonts URL (Puppeteer pas de réseau par défaut, toujours @font-face file:///)
  • ❌ Pas de tagline en rotation -90deg (chevauche le texte)
  • ❌ Pas de big number > 200px sans white-space: nowrap (déborde)

Workflow détaillé pour ajouter un nouveau design

  1. Identifier la marque cible

    Vérifier brands/<id>/brand.json. Si pas existante, créer la charte avant.

  2. Choisir le pattern

    stamp-punchy / editorial-premium / data-driven. Voir wiki/INDEX.md.

  3. Choisir le format

    Par défaut ig-portrait-1080-1350 (format winner). Autres si besoin spécifique.

  4. Copier un template similaire

    Naming : <brand>-<index>-<persona>.html.

  5. Adapter copy, couleurs, logo, stats

    Depuis brand.json. Respecter le tone du champ tone de la marque.

  6. Render

    Render un template
    cd /opt/stack/cg-design && node src/render.js --template <nouveau-nom>

  7. Vérifier visuellement

    Read le PNG dans output/. Détecter overflow, débordements, polices fallback.

  8. Update wiki + log.md

    Pattern Karpathy obligatoire. wiki/notes/brand-<id>.md + ligne dans log.md.

Commandes utiles

Render tous les designs
cd /opt/stack/cg-design && node src/render.js
Render une marque uniquement
node src/render.js --brand autaf
Render un template précis
node src/render.js --template autaf-04-electricien
Voir les logs du service
journalctl -u cg-design-api -f
Redémarrer le service
systemctl restart cg-design-api
