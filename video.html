Production vidéo

Hyperframes, Remotion, Veo3, Kling. Le stack complet pour générer des vidéos TikTok / LinkedIn en quelques minutes.

Les 3 approches

RECOMMANDÉ

🎬 Hyperframes (HTML)

Vidéo composée en HTML/CSS/JS. Determinist, rapide, captions natifs. Le plus simple pour démarrer.

ALTERNATIVE

⚛️ Remotion (React)

Plus mature, large communauté, plein de templates. Demande de comprendre un peu JSX.

100% IA

🤖 Veo3 / Kling direct

Génération vidéo de bout en bout par IA, sans assembler. Magique mais 4-7 clips max et ~$24-$42 par vidéo.

Pipeline @btpmindset (référence)

Voici la pipeline éprouvée qui produit les vidéos virales de @btpmindset (TikTok BTP) :

  1. Script (skill btp-video-script-v3)

    Claude génère un script 9:16 de 30-45s avec hook + 5 perso + CTA. Format DTU 40 (8s/clip, 4-7 clips).

  2. Voix off (ElevenLabs ou Veo3 native)

    Voix Nicolas FR métropolitain, post-prod audio chain (denoise + EQ + loudnorm -14 LUFS).

  3. Génération clips (Veo3 ou Kling)

    Veo3 image-to-video via fal.ai pour les plans réalistes. Kling 2.1 Pro via PiAPI pour l'animation d'images fixes.

  4. Captions auto (Whisper)

    Transcription + alignement word-level. Style jaune sur fond noir, 1 mot à la fois.

  5. Assemblage (Hyperframes ou Remotion)

    Composition finale 1080×1920 avec cuts, overlays, transitions.

  6. Publication (PostFast)

    Upload + schedule sur TikTok / Instagram / LinkedIn avec tracking local des post IDs.

Hyperframes — démarrage

Hyperframes est un framework HTML → vidéo. Vous écrivez du HTML/CSS comme une page web, le framework le rend en .mp4 image par image.

Installation
npm install -g hyperframes
Créer un nouveau projet vidéo
npx hyperframes init mon-clip-tiktok --format=9-16 --duration=30
Preview en temps réel (browser)
cd mon-clip-tiktok && npx hyperframes preview
Render final
npx hyperframes render --output=mon-clip.mp4 --fps=30 --quality=high

Veo3 / Kling — génération directe IA

Quand vous voulez juste 1 clip court "wow effect" sans assembler, vous appelez directement Veo3 ou Kling via fal.ai / PiAPI.

Prompt Veo3 (8s, image-to-video)
Génère un clip Veo3 de 8 secondes en image-to-video à partir de l'image input.jpg. Caméra : slow dolly forward, lighting natural midday, atmosphere realistic. Dialogue : aucun. Pas d'audio. Format 9:16. Utilise le MCP fal avec le modèle veo3/standard/image-to-video.
Prompt Kling 2.1 Pro (5s, animation)
Génère un clip Kling 2.1 Pro de 5 secondes via PiAPI à partir de l'image hook.jpg. Mouvement : l'ouvrier balance la masse vers la caméra. Mode pro, duration 5s. Garde l'image start fidèle.

Audio post-production (chain de-rev)

Une vidéo qui sonne "AI cheap", c'est presque toujours l'audio. Voici le chain ffmpeg qu'on utilise pour rendre une voix off ElevenLabs / Veo3 native plus pro :

Chain audio de-rev + loudnorm (ffmpeg)
ffmpeg -i input.wav -af "highpass=f=80,afftdn=nr=18:nf=-50,equalizer=f=220:width_type=h:width=200:g=-3.5,equalizer=f=420:width_type=h:width=200:g=-2.5,equalizer=f=1100:width_type=h:width=300:g=-1.5,equalizer=f=3200:width_type=h:width=400:g=1.2,acompressor=threshold=-18dB:ratio=3:attack=5:release=50,loudnorm=I=-14:LRA=11:TP=-1" output.wav

Les pièges à connaître

Veo3 et l'accent français. Par défaut, Veo3 parle avec un accent québécois. Toujours préciser "Metropolitan French from Paris, NOT Canadian/Quebec accent" dans le prompt, et écrire les chiffres en toutes lettres.

Veo3 et les filler words. Veo3 ajoute "euh", "tu sais", "quoi" en fin de phrase. Ban explicite dans le prompt : "No filler words. No 'quoi' at the end. Speak with confident assertive tone."

Captions et bourdonnement. Toujours passer l'audio par highpass=80Hz + loudnorm -14 LUFS avant upload TikTok, sinon bourdonnement basse fréquence.
