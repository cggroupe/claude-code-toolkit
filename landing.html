Étape 5 — Tests automatiques avec Playwright

Avant de partager l'URL, on teste visuellement et fonctionnellement :

AVANT déploiement
  • ❌ CTA ne redirige pas où il faut
  • ❌ Formulaire submit ne marche pas
  • ❌ Images cassées sur mobile
  • ❌ Slow loading (3s+ LCP)
  • ❌ Pas de tracking GA4
APRÈS Playwright check
  • ✓ CTA testés mobile + desktop
  • ✓ Form submit + email reçu vérifié
  • ✓ Lighthouse score > 90
  • ✓ LCP < 1.5s, CLS = 0
  • ✓ Events GA4 firing OK
Test E2E via Playwright MCP
Via le MCP Playwright, teste la landing https://landing-electricien-autaf.fr : 1. Ouvre sur desktop (1440×900) et mobile (390×844), screenshot les 2 2. Vérifie que tous les CTA cliquent où il faut 3. Remplis le formulaire avec un test bidon et vérifie qu'il submit + reçoit confirmation 4. Score Lighthouse : performance, accessibilité, SEO, best practices 5. Vérifie que GA4 firing (events page_view + cta_clicked) 6. Sors un rapport markdown avec les screenshots embed + tous les problèmes détectés Si Lighthouse < 90 sur n'importe quelle métrique : propose les 3 fixs prioritaires.
