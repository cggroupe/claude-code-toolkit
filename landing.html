Pré-requis

  • MCP Stitch configuré avec clé Google AI Studio (voir MCP)
  • Compte Vercel (gratuit, vercel.com)
  • Vercel CLI installée : npm install -g vercel
  • Optionnel : MCP Playwright pour tester la landing automatiquement

Le prompt master Stitch

Prompt complet (à adapter)
Via le MCP Stitch, génère-moi une landing page pour [TON BUSINESS]. Contexte business : - Cible : [PERSONA] - Promesse : [VALUE PROP en 1 phrase] - Preuve sociale : [CHIFFRES + LOGOS] - Objection #1 à anticiper : [OBJECTION + RÉPONSE] - CTA principal : [ACTION attendue] Structure : 1. Hero (titre + sous-titre + CTA + visual hero) 2. Logos clients ou chiffres clés 3. "Pour qui" : 3 personas avec icône 4. "Comment ça marche" : 4 étapes numérotées 5. Témoignages : 3 cards avec photo + verbatim 6. Tarifs ou bénéfices (selon modèle) 7. FAQ : 5 questions critiques 8. CTA final + footer Style : - Dark mode haut de gamme (type Linear / Stripe / Vercel) - Accent color : [COULEUR] - Typographie : Inter pour le sans-serif, JetBrains Mono pour code/numbers - Mobile-first - Animations subtiles au scroll (intersection observer) Output : un dossier landing-[NOM]/ avec : - index.html - assets/style.css - assets/app.js (interactions) - README.md (instructions deploy) Prêt à déployer sur Vercel.

Itérer en gardant le contrôle

Une fois la 1ère version sortie, on itère section par section. Pas tout refaire.

Itération ciblée
La section "Pour qui" est bien mais : - Trop générique, manque les pains spécifiques par persona - Active la skill copywriting et propose 3 variantes pour chaque persona - Garde la structure HTML existante, change uniquement le texte - Format : 1 phrase de douleur + 1 phrase de promesse par persona
Audit CRO avant deploy
Active la skill page-cro. Audite la landing actuelle en mode brutal : - Hierarchie visuelle : qu'est-ce qui attire l'œil en premier ? - Friction CTA : combien de clics jusqu'à conversion ? - Manque de preuves sociales ? - Objections non traitées ? - Mobile vs desktop : différences ? Sors-moi un punch list ordonné par impact attendu.

Déploiement Vercel

Premier déploiement
cd landing-mon-business vercel

Vercel va :

  1. Demander de se connecter (1ère fois seulement)
  2. Détecter automatiquement le framework
  3. Donner une URL temporaire de preview
  4. Proposer de "promouvoir" en production avec vercel --prod
Déployer en production
vercel --prod
