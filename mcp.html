MCP & clés API

Branchez Claude Code à des outils externes : design, vidéo, scraping, SEO.

C'est quoi, un MCP ?

MCP = Model Context Protocol. Pensez-y comme à un fournisseur externe que Claude appelle quand il en a besoin. Sans MCP, Claude sait écrire du texte et du code. Avec MCP, il peut générer des maquettes, des vidéos, scraper des sites, lire vos emails.

Métaphore BTP. Claude tout seul, c'est un excellent conducteur de travaux. Mais sans téléphone, il ne peut pas appeler le couvreur, le plombier ou l'électricien. Les MCP, ce sont ses contacts métier.

Comment ça s'installe ?

Trois façons d'ajouter un MCP à Claude Code :

  1. Via la commande CLI (la plus simple)
  2. Via le fichier ~/.claude/settings.json (pour personnalisation fine)
  3. Via le marketplace Claude (pour les MCP officiels Anthropic — auth en 1 clic)

Commande générique pour ajouter un MCP

Installation MCP via CLI
claude mcp add <nom> -- npx -y <package>

Ou pour passer une clé API en variable d'environnement :

Avec clé API
claude mcp add <nom> --env API_KEY=<votre_clé> -- npx -y <package>

Les 6 MCP du toolkit marketing

🎨
Stitch DESIGN Google
Génère des maquettes UI complètes (landing, app, dashboard) à partir d'un prompt en français. Magique pour démarrer un projet web.

Usage typique : "fais-moi une landing page sombre pour une boîte de BTP avec hero, témoignages clients, formulaire devis". Output : maquette HTML/CSS prête à exporter.

Où chopper la clé API

  1. Allez sur aistudio.google.com/apikey
  2. Connectez-vous avec votre compte Google
  3. Cliquez "Create API key"
  4. Copiez la clé qui commence par AIza...
  5. Note : Stitch utilise la même API key que Gemini (Google AI Studio)

Installation

Installer Stitch MCP
claude mcp add stitch --env GOOGLE_API_KEY=VOTRE_CLE -- npx -y @google/stitch-mcp
stitch.withgoogle.com obtenir la clé
🎬
fal.ai VIDÉO / IMAGE Veo3, Flux, Wan
Accès aux modèles vidéo et image les plus puissants : Veo3 (vidéo 8s ultra-réaliste), Flux Pro (image), Wan 2.2. Le moteur derrière @btpmindset.

Usage typique : "génère 5 clips Veo3 de 8s pour TikTok montrant des artisans BTP en chantier". Output : 5 fichiers .mp4 prêts à monter.

Où chopper la clé API

  1. Allez sur fal.ai et créez un compte
  2. Cliquez votre avatar → Dashboard
  3. Onglet API Keys → Add new key
  4. Copiez la clé qui ressemble à aaa-bbb-ccc:dddeee...
  5. Rechargez votre solde (minimum 5$) — Veo3 coûte ~6$ par clip de 8s

Installation

Installer fal.ai MCP
claude mcp add fal --env FAL_KEY=VOTRE_CLE -- npx -y @fal-ai/mcp-server

⚠️ Budget. Veo3 standard = $0.75/seconde × 8s = $6 par clip. Une vidéo TikTok = 4-7 clips = $24-$42. Posez-vous toujours la question "combien je veux dépenser ce soir" avant de lancer.

fal.ai obtenir la clé modèles dispo
🎞️
PiAPI VIDÉO / IMAGE / MUSIQUE Kling, Midjourney, Suno
Accès unifié à Kling 2.1 (image-to-video), Midjourney (image), Suno (musique). Alternative ou complément à fal.ai.

Usage typique : "anime cette image fixe avec Kling 2.1 Pro" → vidéo 5s où l'ouvrier bouge vraiment. Pratique pour les hooks animés TikTok.

Où chopper la clé API

  1. Allez sur piapi.ai et créez un compte
  2. Choisissez un plan (Starter = pay-as-you-go, recommandé pour démarrer)
  3. Dashboard → API Keys → Generate
  4. Copiez la clé (format xxxxxxxx-xxxx-...)
  5. Rechargez votre solde ($10 minimum)

Installation

Installer PiAPI MCP
claude mcp add piapi --env PIAPI_KEY=VOTRE_CLE -- npx -y @piapi-ai/mcp-server
piapi.ai dashboard
🕷️
Apify SCRAPING 3000+ actors
Scrape n'importe quel site web : TikTok, LinkedIn, Google Maps, PagesJaunes, Instagram, Indeed. 3000+ "actors" prêts à l'emploi.

Usage typique : "scrape les 100 premiers résultats Google Maps pour 'couvreur Brest' avec téléphone, site et avis Google". Output : CSV prêt à enrichir.

Où chopper la clé API

  1. Allez sur apify.com et créez un compte
  2. Plan gratuit = 5$ de crédit/mois (largement suffisant pour démarrer)
  3. Allez sur console.apify.com/account/integrations
  4. Copiez votre Personal API token (format apify_api_xxxxx)

Installation

Installer Apify MCP
claude mcp add apify --env APIFY_TOKEN=VOTRE_TOKEN -- npx -y @apify/actors-mcp-server

💎 Le must-have pour la prospection. 1 token Apify + Claude Code = équivalent d'un commercial junior qui scrape 500 prospects en 1h.

apify.com obtenir le token marketplace actors
📊
DataForSEO SEO / SERP
Données SEO en temps réel : positions Google, volumes de recherche, backlinks, analyse concurrence. Le couteau suisse SEO.

Usage typique : "donne-moi les 100 mots-clés rentables pour 'rénovation maison Brest' avec volume, difficulté et intention". Output : tableau prêt à briefer un rédacteur.

Où chopper la clé API

  1. Allez sur app.dataforseo.com/register
  2. Créez un compte (vérification email)
  3. Rechargez votre solde ($10 minimum, paiement à la requête)
  4. Allez sur API Access → notez vos identifiants login et password

Installation

Installer DataForSEO MCP
claude mcp add dataforseo --env DATAFORSEO_USERNAME=login --env DATAFORSEO_PASSWORD=mdp -- npx -y dataforseo-mcp-server

Pricing. ~$0.001 par mot-clé (très peu cher). $10 = ~10 000 requêtes. Largement de quoi auditer un site complet.

dataforseo.com obtenir les credentials
🌐
Playwright GRATUIT Microsoft
Donne à Claude un vrai navigateur. Il peut cliquer, remplir des formulaires, prendre des screenshots, tester vos landing pages.

Usage typique : "vérifie que le formulaire de contact AUTAF marche : remplis-le avec un faux test et confirme la soumission". Ou : "screenshot le site concurrent et résume-moi leur structure".

Où chopper la clé API

Aucune clé. Playwright est gratuit, il tourne en local sur votre machine.

Installation

Installer Playwright MCP
claude mcp add playwright -- npx -y @playwright/mcp@latest
github playwright.dev

MCP officiels Anthropic (auth 1 clic)

Ces MCP s'installent depuis l'interface Claude Code (menu Settings → MCP) sans clé API à gérer — l'authentification se fait par OAuth en 1 clic.

📧 Gmail

Lire et envoyer des emails depuis Claude. Idéal pour les workflows prospection.

📅 Google Calendar

Lire votre agenda, créer des RDV. Utile pour le suivi commercial.

📁 Google Drive

Lire/écrire des docs Google Docs et Sheets. Indispensable si vous travaillez en équipe.

💬 Slack

Lire les messages, poster dans un canal. Notifications automatiques quand un workflow finit.

MCP built-in (déjà inclus)

Claude Code intègre nativement plusieurs capacités, sans installation :

  • Filesystem — lire, créer, modifier les fichiers sur votre disque
  • Bash — lancer des commandes terminal
  • Memory — sauvegarder des informations entre sessions
  • WebSearch / WebFetch — chercher sur internet et lire des pages

Comment vérifier qu'un MCP marche ?

  1. Lancez Claude Code dans VS Code
  2. Tapez /mcp pour voir la liste des MCP connectés
  3. Si un MCP est en rouge, c'est qu'il y a un souci (clé API invalide, package manquant)
  4. Demandez à Claude : "quels MCP tu as actuellement et qu'est-ce que tu peux faire avec ?"

🚨 Sécurité. Ne mettez jamais vos clés API directement dans un fichier que vous publiez sur GitHub. Toujours via variables d'environnement ou via claude mcp add --env. Si vous leakez une clé, révoquez-la immédiatement.
