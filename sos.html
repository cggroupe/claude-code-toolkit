SOS pannes 🆘

Les erreurs courantes et leur correction. Cherchez Ctrl+F votre symptôme.

Claude Code en général

🔁
Claude boucle sur la même mauvaise piste

Symptôme. Vous lui demandez X, il fait Y, vous corrigez, il refait Y, etc.

Fix.

  1. Tapez /clear pour vider le contexte
  2. Reformulez en étant plus explicite sur ce que vous ne voulez pas
  3. Si ça boucle encore : passez en /plan mode et lisez le plan avant exécution
🧠
Claude "oublie" ce qu'il vient de faire

Symptôme. Vous reprenez le projet 3 jours après, il a perdu le contexte.

Fix. Adoptez le pattern Karpathy. Avec un wiki à jour, Claude relit avant d'agir. Et utilisez /memory pour les préférences perso.

💸
Vous avez brûlé votre crédit fal.ai / PiAPI sans résultat

Symptôme. 6 essais Veo3 à $6 chacun = $36 et aucune vidéo utilisable.

Fix. Toujours dire en début de prompt "Budget max : $X. Si tu dépasses ou risques de dépasser, stop et demande validation". Et faites toujours un test 1 clip avant de lancer 5 clips.

Veo3 / fal.ai

🇨🇦
Veo3 parle québécois

Symptôme. Votre personnage français a un accent canadien.

Fix. Dans le prompt :

Forcer FR métropolitain
Speak in Metropolitan French from Paris, NOT Canadian/Quebec French. Write all numbers in full letters. No filler words like "quoi" or "tu sais" or "euh".
🤐
Veo3 ajoute "quoi", "euh", "tu sais" en fin de phrase

Symptôme. Le ton sonne familier au lieu de pro.

Fix. Ban explicite des filler words + verbatim-lock (dialogues exacts).

🚫
"401 Unauthorized" sur fal.ai

Symptôme. L'appel Veo3 échoue avec une erreur d'authentification.

Fix.

  1. Vérifiez que votre clé fal.ai est valide sur fal.ai/dashboard/keys
  2. Vérifiez le bon endpoint : depuis 2026, c'est /fal-ai/veo3/standard/image-to-video (et pas /fal-ai/veo3/image-to-video)
  3. Vérifiez votre solde (Veo3 = $6/clip, il faut au moins ça)

Apify

⏰
Actor Apify timeout / queue infinie

Symptôme. Vous lancez un actor, il reste en "Running" sans rien produire.

Fix.

  • Vérifiez que vous avez encore du crédit Apify (les actors plus chers consomment vite)
  • Si l'actor a un memoryMbytes élevé : abaissez-le pour aller plus vite
  • Si toujours bloqué : kill le run depuis console.apify.com/runs et relancez avec maxConcurrency=1

PostFast

👯
Publication en doublon sur TikTok

Symptôme. Une même vidéo a été publiée 2 fois.

Cause. L'API PostFast /social-posts?limit=50 est buggée (renvoie un nombre random d'items, hasNextPage=false menteur).

Fix. Toujours tracker localement les post IDs dans output/scheduled-postids.json. Avant de schedule une nouvelle vidéo, vérifier que son chemin n'est pas déjà dans le tracking.

Hyperframes / Remotion

🌀
Render Chrome super lent (6s/frame)

Symptôme. Le render Hyperframes / Remotion prend 30 min pour 30s de vidéo.

Causes possibles.

  • SVG très dense (> 50 éléments) dans la compo → simplifiez
  • --public-dir trop volumineux (charge tous les assets en mémoire) → ne mettre que les assets utilisés
  • Ubuntu 24.04 : restriction apparmor sur les userns → sysctl -w kernel.apparmor_restrict_unprivileged_userns=0
🔊
Bourdonnement audio dans la vidéo finale

Symptôme. Un grave bourdonnement basse fréquence audible sur TikTok.

Fix. Toujours appliquer highpass=80Hz + loudnorm I=-14 LRA=11 TP=-1 sur l'audio avant export. Voir page Vidéo pour la chain complète.

n8n

🚫
$env ne marche pas dans n8n

Symptôme. Vous référencez $env.MA_VARIABLE dans un node, valeur vide.

Cause. Depuis n8n v2.8+, l'expression $env est bloquée pour raisons de sécurité.

Fix. Hardcoder les valeurs dans le node, ou utiliser les credentials n8n natifs (Settings → Credentials).

⏲️
Workflow Schedule n8n qui ne tourne pas en prod

Symptôme. Le workflow tourne en test mais pas via le node Schedule.

Cause. Le node Schedule est instable pour les process longs.

Fix. Utiliser un service systemd qui appelle le workflow via webhook, à la place du node Schedule.

VS Code / installation

🔌
Claude Code n'apparaît pas dans VS Code après install

Fix.

  1. Reload window : Cmd+Shift+P → "Reload Window"
  2. Vérifiez l'icône Claude dans la barre latérale gauche (en bas)
  3. Si toujours rien : Cmd+Shift+P → "Claude Code: Open"
  4. Si toujours rien : désinstaller / réinstaller l'extension
🔐
Erreur "Cannot find module" sur npm install

Fix.

Reset npm
rm -rf node_modules package-lock.json && npm install

Astuces générales

💡 Quand vous ne comprenez pas une erreur. Copiez-collez le message d'erreur exact dans Claude Code et demandez "explique cette erreur et propose 3 fixs possibles". 90% du temps il trouve.

💡 Avant d'abandonner. Tapez /clear, prenez 30s, reformulez votre demande différemment. Souvent c'est juste un malentendu sur le prompt initial.

🚨 Ne supprimez jamais. Quand vous voulez désinstaller un MCP : claude mcp remove <nom>. Quand vous voulez nettoyer une session : /clear (et pas la corbeille). Ne supprimez jamais manuellement le dossier ~/.claude/, vous perdriez toute votre mémoire.
