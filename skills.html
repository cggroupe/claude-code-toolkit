Skills

Les "fiches métier" qui apprennent à Claude un savoir-faire spécifique. À télécharger, copier, adapter.

C'est quoi, une skill ?

Une skill, c'est un fichier markdown qui décrit à Claude une compétence précise : comment écrire un post LinkedIn viral, comment auditer une page SEO, comment générer un script TikTok BTP. Quand Claude détecte que la situation correspond, il active automatiquement la skill et suit le protocole décrit.

Métaphore. Une skill, c'est la fiche métier qu'on glisse dans le classeur du stagiaire. "Quand un client demande X, voici comment tu procèdes, étape par étape." Le stagiaire la consulte chaque fois qu'il en a besoin.

Comment ça s'installe ?

Option A — Via un plugin Claude Code

Le plus simple : la skill est packagée dans un plugin community, vous l'installez en une commande.

Installer un pack de skills marketing
/plugins install marketing-skills

Option B — Manuellement depuis GitHub

Vous téléchargez le fichier SKILL.md et vous le placez dans ~/.claude/skills/<nom>/SKILL.md.

Installation manuelle (Mac/Linux)
mkdir -p ~/.claude/skills/copywriting && curl -fsSL https://raw.githubusercontent.com/anthropics/skills/main/marketing/copywriting/SKILL.md -o ~/.claude/skills/copywriting/SKILL.md

Option C — Créer la vôtre

Demandez à Claude lui-même de vous la générer :

Prompt génération de skill
Crée-moi une skill Claude Code qui s'appelle "post-linkedin-pro". Elle doit se déclencher quand je demande un post LinkedIn. Le format à respecter : hook (1 ligne choc), 5 insights numérotés, CTA en dernier. Style B2B sénior, pas de buzzwords. Sauvegarde-la dans ~/.claude/skills/post-linkedin-pro/SKILL.md.

Anatomie d'une skill (pour comprendre)

Un fichier SKILL.md ressemble à ça :

---
name: copywriting
description: Écrit du copy persuasif. Trigger sur "headline", "copy", "tagline"...
allowed-tools:
  - Read
  - Write
---

# Copywriting Skill

## When to use
Quand l'utilisateur demande un headline, body copy, CTA, tagline.

## Process
1. Identifier l'audience cible (à demander si pas clair)
2. Choisir un framework (AIDA, PAS, BAB)
3. Écrire 3 variantes
4. Marquer la variante recommandée

## Output format
- 3 variantes numérotées
- 1 ligne d'explication par variante
- Variante recommandée marquée ⭐

Le frontmatter YAML en haut dit à Claude quand activer la skill. Le markdown en dessous dit comment procéder.
