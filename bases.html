Les 8 commandes vitales ⌨️

Tout ce qu'il faut savoir. Pas besoin de mémoriser — tapez / dans Claude Code et un menu apparaît.

La règle d'or. Vous n'apprenez pas, vous explorez. Le menu / liste tout en temps réel.

Le quotidien
❓
/help
L'aide intégrée. Liste toutes les commandes dispo avec leur description.
🧹
/clear
Efface la conversation. À utiliser quand Claude part en vrille.
⏪
/resume
Reprend une session précédente. Idéal pour repartir le matin.
📂
/init
Initialise un nouveau projet. Crée CLAUDE.md avec le contexte.
🧠
/memory
Gère la mémoire long-terme. Ce que Claude retient entre sessions.
👥
/agents
Délègue à un sous-agent spécialisé. Pour les tâches longues.
📋
/plan
Mode plan. Claude propose, vous validez, puis il exécute.
🧩
/plugins
Installe des plugins community (skills, commandes, MCP).
Détails par commande

Quand l'utiliser : dès que vous avez un doute.

Exemple
/help

Quand l'utiliser : Claude tourne en rond ou nouveau sujet sans rapport.

⚠️ Important : /clear efface la conversation mais pas les fichiers déjà créés sur le disque.

Reset
/clear

Quand l'utiliser : début de journée, pour reprendre où vous vous étiez arrêté.

Reprendre
/resume

Quand l'utiliser : la première fois que vous travaillez sur un nouveau dossier.

Init
/init

Quand l'utiliser : pour les préférences qui doivent tenir entre sessions.

Sous-agent

Plan mode

Commandes complémentaires

▶️
