Les bases

Les 8 commandes à connaître par cœur. Vous ne lirez pas 100 pages de doc.

Comment ça marche, une commande ?

Une commande commence par / (slash). Vous tapez / dans le chat et un menu apparaît avec toutes les commandes disponibles. Vous pouvez aussi parler en français normal : Claude comprend.

💡 La règle d'or. Vous n'avez pas à mémoriser les commandes. Tapez / et explorez. La doc est dans le menu.

Les 8 commandes vitales

❓
/help Quotidien
L'aide intégrée. Liste toutes les commandes disponibles avec leur description.

Quand l'utiliser : dès que vous avez un doute sur ce qui existe.

Exemple
/help
🧹
/clear Quotidien
Vide la conversation en cours. Claude oublie ce qui vient d'être dit.

Quand l'utiliser : quand Claude s'égare et tourne en rond, ou quand vous passez à un sujet complètement différent. Comme jeter un brouillon et reprendre une feuille blanche.

Exemple
/clear

⚠️ Attention. /clear efface la conversation mais pas les fichiers créés. Vos fichiers sur le disque restent intacts.

⏪
/resume Pratique
Reprendre une conversation précédente. Très utile quand vous fermez VS Code et revenez le lendemain.

Quand l'utiliser : en début de journée, pour reprendre où vous vous êtes arrêté.

Exemple
/resume
📂
/init Important
Initialise un projet Claude Code. Crée un fichier CLAUDE.md qui décrit votre projet pour que Claude le comprenne à chaque session.

Quand l'utiliser : la première fois que vous travaillez sur un nouveau dossier. Claude analyse votre projet et écrit lui-même le fichier de présentation.

Exemple
/init

Métaphore. C'est comme rédiger le "livret d'accueil" du projet pour le stagiaire. À chaque retour au bureau, le stagiaire relit le livret avant de bosser.

🧠
/memory Important
Gère la mémoire long-terme. Ce que Claude doit se souvenir entre les sessions.

Quand l'utiliser : quand vous voulez que Claude retienne une préférence personnelle ("je travaille en français", "ne crée jamais de code dans ce dossier"), un contexte business ("notre boîte fait du BTP, notre cible c'est les artisans").

Sauvegarder une préférence
Remember: je travaille en français. Toutes les explications en français, code et commentaires en anglais.

💎 Power tip. Plus vous nourrissez la mémoire, plus Claude devient pertinent. Au début c'est un stagiaire qui ne vous connaît pas, après 2 semaines c'est un collègue qui vous comprend.

👥
/agents Avancé
Délègue une tâche à un sous-agent spécialisé. Comme appeler un collègue expert sur un sujet précis.

Quand l'utiliser : pour des tâches longues ou spécifiques. Exemple : "lance un agent qui fait l'audit SEO complet du site pendant que je continue mon travail".

Lancer un sous-agent
Lance un agent qui scrape PagesJaunes pour me sortir 50 plombiers à Brest avec leur téléphone et leur site web.
📋
/plan ou Plan Mode Important
Bascule en mode plan. Claude réfléchit, propose un plan d'action, mais ne fait rien tant que vous n'avez pas approuvé.

Quand l'utiliser : avant une grosse tâche (refonte d'un site, gros refactor). On vérifie le plan, on ajuste, puis on lance l'exécution.

Activer le plan mode
Passe en plan mode. Propose-moi un plan pour créer une landing page complète AUTAF avec hero, témoignages, pricing et CTA. Ne code rien tant que je n'ai pas validé.

Raccourci VS Code. Vous pouvez aussi appuyer sur Shift+Tab pour basculer en plan mode rapidement.

🧩
/plugins Important
Installer un plugin community qui ajoute des compétences à Claude (skills, commandes, agents).

Quand l'utiliser : pour récupérer un kit complet sans coder. Exemple : installer le pack SEO de la communauté.

Parcourir le marketplace

Les commandes qui complètent

/skill <nom>

Invoque manuellement une skill (une fiche métier spécifique). Exemple : /skill copywriting pour activer le mode rédaction.

/run

Lance l'app du projet en cours pour voir le résultat (utile en dev web : démarre le serveur local et capture un screenshot).

/review

Lance une revue de code complète. Claude relit ce qu'il a fait et propose des améliorations.

/security-review

Audit de sécurité (failles OWASP, secrets en clair, injection). À lancer avant toute mise en prod.

/loop

Répète une tâche en boucle à intervalle régulier. Exemple : "scrape les nouveaux artisans tous les jours à 8h".

/schedule

Programme une action récurrente côté serveur Anthropic (cloud), pas votre machine. Utile pour le monitoring.

Styles (output styles)

Les output styles changent le ton et le format des réponses de Claude. Par défaut Claude est concis et direct. Vous pouvez le mettre en mode "pédagogue", "concis", "verbeux", etc.

Lister les styles
/output-style

À utiliser selon le moment :

  • Default — pour le travail quotidien
  • Explanatory — quand vous voulez comprendre, pas juste obtenir un résultat
  • Concise — quand vous êtes pressé et savez ce que vous faites
